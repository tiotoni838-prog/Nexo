# NexoChat — chat estilo ChatGPT en Android

App de chat con streaming en tiempo real, tema oscuro y burbujas estilo ChatGPT.

## Cómo usarlo

1. Descarga el APK desde la pestaña **Actions** (flujo *APK · NexoChat* → artefacto
   `NexoChat-debug-apk`) e instálalo.
2. Toca **⚙**, pega tu **API key** y elige **URL de la API** y **modelo**:
   - OpenAI: `https://api.openai.com/v1` · `gpt-4o-mini`
   - Mistral: `https://api.mistral.ai/v1` · `mistral-large-latest`
   - Groq: `https://api.groq.com/openai/v1` · `llama-3.1-70b-versatile`
   - DeepSeek: `https://api.deepseek.com/v1` · `deepseek-chat`
3. Habla — las respuestas aparecen token a token como en ChatGPT, y el chat se guarda
   en el teléfono. **＋ Nuevo** borra la conversación.

Funciona con cualquier API compatible con OpenAI, incluidos servidores locales.
