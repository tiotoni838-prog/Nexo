# Descargas de Nexo FPS

## v1.6.0

- **NexoFPS-1.6.0-windows-x64.zip** — **aplicación nativa de Windows** (Electron 33).
  Descomprime y ejecuta `nexo-fps.exe`. Sin navegador.
- **NexoFPS-1.6.0-linux-x64.zip** — **aplicación nativa de Linux**.
  Descomprime y ejecuta `./nexo-fps`. Sin navegador.
- **macOS**: se genera localmente con `cd game && npm run desktop`
  (`game/dist-desktop/NexoFPS-darwin-x64` y `-arm64`). No se aloja en Git porque
  supera los 100 MB por archivo que permite GitHub.
- **NexoFPS-1.6.0-web-standalone.zip** — el juego completo en un solo HTML.
  Descomprime, abre `NexoFPS.html` con doble clic y juega (Entrenamiento contra
  bots, sin internet). Windows / macOS / Linux / navegador del teléfono.
- **NexoFPS-1.6.0-servidor.zip** — servidor dedicado para partidas online
  (Node.js 20+), con tienda PayPal, panel de ganancias, cuentas con 2FA,
  amigos, clanes, rankings y códigos de canje.

- **NexoFPS-1.6.0-android.apk** — **APK nativa de Android** (WebView a pantalla
  completa, controles táctiles, Android 5.0+, firmada). Descárgala en el
  teléfono, permite «Instalar apps desconocidas» e instala.

### Android (APK) e iOS

Cada dispositivo tiene su forma de descarga:

- **Android**: proyecto WebView nativo listo para Android Studio → genera el APK
  (instrucciones en `docs/OPERATIONS.md`). Cuando se publique en Play Store, el
  APK se distribuirá desde allí.
- **iOS**: requiere Xcode en macOS para firmar e instalar en iPhone
  (instrucciones en `docs/OPERATIONS.md`). Cuando se publique en la App Store,
  la descarga será desde allí.

Para descargar un .zip de esta carpeta: entra al archivo y pulsa el botón
**"Download raw file"**.

Página con botones por plataforma (la sirve el propio juego): `http://<servidor>:8080/download`

¿Discord? Guía lista en discord/DISCORD.md.
