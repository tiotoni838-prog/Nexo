# Nexo

Repositorio del ecosistema Nexo. Contiene tres proyectos:

| Carpeta | Qué es | Dónde corre |
|---|---|---|
| [`NexoChat/`](NexoChat/README.md) | App Android: chat de IA estilo ChatGPT con streaming | Tu teléfono |
| [`NexoBot/`](NexoBot/README.md) | App Android: tu bot de Discord 24/7 hospedado en tu teléfono (conecta Discord + API de IA) | Tu teléfono |
| [`clipbot/`](clipbot/README.md) | Bot de Discord que convierte videos largos en clips verticales con subtítulos (yt-dlp + Whisper + IA + FFmpeg) | PC o VPS |

## APKs

Los APK instalables se compilan automáticamente con GitHub Actions: pestaña **Actions** →
flujo *APK · NexoChat* o *APK · NexoBot* → descarga el artefacto.
